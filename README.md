# Fiscal Generator

Simulador educacional de **NF-e, CT-e e MDF-e**, inspirado no fluxo visual de sistemas fiscais reais.

> **Importante:** este projeto não possui validade fiscal e não realiza comunicação com a SEFAZ. Todos os documentos, chaves, autorizações e eventos são simulados.

## Objetivo

Criar um ambiente seguro para estudar:

- estrutura de documentos fiscais eletrônicos;
- campos e relacionamentos entre NF-e, CT-e e MDF-e;
- fluxos de emissão e histórico;
- representação visual de documentos;
- conceitos de numeração, série, emitente, destinatário, carga e transporte.

## Tecnologia

Aplicação estática em HTML, CSS e JavaScript, sem backend e sem dependências de runtime. Os documentos ficam apenas no `localStorage` do navegador.

## GitHub Pages

O projeto inclui workflow de deploy em `.github/workflows/pages.yml` para publicação pelo GitHub Pages.
